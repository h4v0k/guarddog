GUARD DOG

v__VERSION__ · build __BUILD__ · M5Stack Fire / Core (ESP32)

Flash it

  1. Use Chrome or Edge on a computer (Web Serial).
  2. Plug the M5Stack in with a USB-C data cable.
  3. Click Install, pick the serial port (CP210x / CH9102), confirm erase.
This browser can't flash over USB. Use desktop Chrome or Edge. Flashing needs HTTPS. Download .bin

Manual: esptool.py --chip esp32 write_flash 0x0 guarddog.bin. To go back to stock, re-flash the factory image from M5Burner.

Controls

  • A (left) up · C (right) down · hold to scroll
  • B (middle) click = select / action · hold B = back
